The 5 columns (and what the importer expects)

The template matches SteelCut's Excel import exactly — what you fill in is what gets optimised. No reformatting needed.

ColumnHeaderRequiredNotes
ALengthYes — number > 0Any row whose length is not a number is skipped, so titles and notes are safe.

Frequently asked questions

What columns should a rebar cutting list template have?
At minimum: length, quantity, unit, label (member/mark) and bar diameter. This template uses exactly these five columns and imports directly into the optimizer.

How do I turn a cutting list into an optimised cutting plan?
Fill in the template, then import the file into SteelCut (Open app → Import → Excel). The list loads instantly and the optimizer computes the cutting plan with minimum waste.

Is the template free?
Yes — free to download and use, no account, no watermarks.
